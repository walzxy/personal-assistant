# Xiao Yu · Personal Daily Assistant

这是个人日常管理小秘书的第一版前端原型。当前使用浏览器 `localStorage` 保存数据，适合先验证信息架构和交互；后续可以把同一套数据模型迁移到云端数据库，并接入 OpenClaw API。

## 本地运行

在项目目录执行：

```powershell
node serve.mjs
```

然后打开：

```text
http://127.0.0.1:4173
```

## 当前已实现

- 响应式三栏布局，移动端抽屉式导航；
- 任务页作为当前首页；
- Regular Task、Standalone Task、Long-term Task 和 Sub-task 展示；
- 任务创建、任务详情、10 格进度条；
- 已创建任务可编辑标题、日期、DDL、预计时长、难度、备注和任务颜色；
- Regular Task 最多 3 个同级子任务，Long-term Task 支持子任务确认完成；
- 任务计时开始/暂停；
- 100% 后进入确认完成状态；
- 今日、周、月视图；
- 周/月习惯 KPI 与当日打卡；
- 统一课程/任务时间轴；
- 莫兰迪任务色库：灰蓝、鼠尾草绿、干枯玫瑰、燕麦、香芋紫、灰橘、灰青、浅灰粉；
- 课表 JSON 导入预览和实例生成；
- 任务与课程时间重叠提示；
- 数据导出；
- Reading、Xiao Yu message board、Archive、Inspiration box 占位入口。

## 当前暂不实现

- 奖励抽奖和 Archive 数据逻辑；
- 阅读清单和阅读笔记；
- Xiao Yu 对话界面；
- 云端账户、数据库和多设备同步；
- 独立课程推送提醒；
- OpenClaw 写入接口。
